# sheet-to-classroom-score
將試算表成績自動填入Google Classroom  
安裝方式：  
點選右上角綠色的「<>Code」按鈕，再點選「Download ZIP」，把下載的檔案存到你指定的資料夾(例如：文件)。  
解壓縮檔案，會得到一個「sheet-to-classroom-score-main」的資料夾。  
把 Chrome 的左上角三小點打開，然後選擇「擴充功能」、「管理擴充功能」，會跳出擴充功能管理的分頁。  
打開右上角的「開發人員模式」，這時左上方會出現「載入未封裝項目」的按鈕。按下這個按鈕，資料夾就選擇你剛才解壓縮的那個資料夾(例如：文件\sheet-to-classroom-score-main)。  
這時候擴充功能就安裝好了，請回到 Google Classroom 按一次 F5 重新整理畫面就會啟用了。
